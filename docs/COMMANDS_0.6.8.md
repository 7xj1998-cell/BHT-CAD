# Lệnh BHT v0.6.8

Gõ `BHT` hoặc `BTH` để mở bảng. Đã bỏ 14 bí danh Lisp và hai bí danh mở bảng; dùng các lệnh chính dưới đây trong script CAD.

| Bí danh đã bỏ | Lệnh thay thế |
|---|---|
| `BHTIMPORT` | `BHTNHAP` |
| `BHTCSV` | `BHTNHAP` |
| `BHTNK` | `BHTNHAPTSV` |
| `BHTLABEL` | `BHTNHANDIEM` |
| `BHTTAG` | `BHTDOITUONG` |
| `BHTEDIT` | `BHTSUADT` |
| `BHTDELETE` | `BHTXOADT` |
| `BHTUNTAG` | `BHTBOTDIEM` |
| `BHTDSANH` | `BHTANHNAP` |
| `BHTSYNCANH` | `BHTDONGBOANH` |
| `BHTPHOTO` | `BHTGANANH` |
| `BHTEXPORT` | `BHTXUAT` |
| `BHTSUMMARY` | `BHTXUAT` |
| `BHTCHECK` | `BHTKT` |
| `BHTSHOW` | `BHT` |
| `BHTPALETTE` | `BHT` |

Các lệnh `BHTNET*` được giữ vì bộ kiểm thử tích hợp dùng chúng để đối chiếu dữ liệu Lisp với .NET và kiểm tra điều phối CAD.
