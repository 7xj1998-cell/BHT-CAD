# BHT — công cụ quản lý hiện trạng tuyến cho AutoCAD

Kho mã nguồn **riêng tư** (private) của BHT: AutoLISP + plugin .NET cho AutoCAD 2024 để quản lý dữ liệu hiện trạng tuyến
(điểm đo RTK, hồ sơ đối tượng, ảnh liên kết, ký hiệu / nhãn).

* Không đưa vào repo: DLL/EXE (kể cả DLL của Autodesk), bản vẽ DWG, ảnh, dữ liệu khảo sát thật (CSV, KMZ), gói phát hành ZIP.
* Mã nguồn nằm trên các nhánh `fix/bht-0.3.3` và `feature/bht-0.4.0-palette` (xem Pull Request).
